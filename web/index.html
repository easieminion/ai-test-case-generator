SpecProof Checking provider

Requirements in. Tested, measured, reported.

Write what the code must do. Review the tests an LLM drafts, run them with coverage, and download the report as PDF, Word or HTML.

1

Requirements

Describe what the code must do. Number the requirements (R1, R2, ...) so each test can point back to one. You can edit this text at any time and regenerate.

Code under test (optional)

Paste the code to test (it is imported as solution), or leave this empty and the LLM writes a reference implementation too.

2

Review the tests

Tests are always ordered Positive, Negative, Edge case. Each one carries its explanation as a code comment. Edit or delete anything, and add what is missing.

3

Run with coverage

Tests run in a subprocess with a timeout. Results and statement coverage are collected automatically.

4

Report

Choose the document type. PDF is the default.
