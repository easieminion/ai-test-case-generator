AI Test Case Generator

requirements → LLM tests → automated run with coverage → report checking provider...

1 · Requirements

Describe what the code must do. Number the requirements (R1, R2, ...) so tests can point back to them. You can edit this text at any time and regenerate.

Code under test (optional)

Paste the code to test (it is imported as solution), or leave empty and the LLM writes a reference implementation too.

2 · Review the tests

Order is always Positive → Negative → Edge case. Each test has its explanation as a code comment. Edit or delete anything, and add what is missing.

3 · Run with coverage

Tests run in a subprocess with a timeout. Results and line coverage are collected automatically.

4 · Report

Choose the document type. PDF is the default.
